1. Project Overview

UpGrades is a full-stack AI-powered study planner web application. It solves a real problem: students receive a course syllabus but don't know how to turn it into a structured, day-by-day study plan.

What the app does:

  1. Upload a syllabus — drag-and-drop a PDF file or paste raw text
  2. AI generates a study plan — Google Gemini AI analyzes the syllabus and creates a personalized, week-by-week plan with daily topics, resources, and time allocations
  3. Track progress — mark topics as complete, view percentage progress, follow daily missions
  4. Chat with an AI tutor — ask questions about any topic and get contextual help
  5. Study groups — compete with peers on leaderboards, earn XP, maintain streaks
  6. Customize preferences — AI teaching style, accessibility settings, account management

6
Theme Context — Dark/Light Mode
export const ThemeProvider = ({ children }) => {
  const [isDark, setIsDark] = useState(() => {
    const saved = localStorage.getItem('upgrades-theme');
    if (saved) return saved === 'dark';
    return window.matchMedia('(prefers-color-scheme: dark)').matches;
  });

  useEffect(() => {
    if (isDark) {
      document.documentElement.setAttribute('data-theme', 'dark');
      localStorage.setItem('upgrades-theme', 'dark');
    } else {
      document.documentElement.removeAttribute('data-theme');
      localStorage.setItem('upgrades-theme', 'light');
    }
  }, [isDark]);

  const toggleTheme = () => setIsDark(prev => !prev);
  return <ThemeContext.Provider value={{ isDark, toggleTheme }}>{children}</ThemeContext.Provider>;
};

Checks localStorage first, then OS preference. Sets data-theme="dark" on <html> to trigger CSS overrides. Persists choice across refreshes.

7
Auth Context — Authentication State

Manages user session globally with Supabase Auth:

useEffect(() => {
  // Get existing session on mount
  supabase.auth.getSession().then(({ data: { session } }) => {
    setSession(session);
    setUser(session?.user ?? null);
    setLoading(false);
  });

  // Listen for all auth changes (login, logout, token refresh)
  const { data: { subscription } } = supabase.auth.onAuthStateChange(
    (_event, session) => {
      setSession(session);
      setUser(session?.user ?? null);
    }
  );
  return () => subscription.unsubscribe();
}, []);

Exposes methods: signInWithEmail, signUpWithEmail, signInWithGoogle, signInWithGithub, signInWithOtp, verifyOtp, signOut, plus state: user, session, loading, isAuthenticated.

9
API Layer — Backend Communication
export async function callBackendWithAuth(endpoint, options = {}) {
  const { data: { session } } = await supabase.auth.getSession();
  if (!session) throw new Error('Not authenticated.');

  const response = await fetch(`${BACKEND_URL}${endpoint}`, {
    ...options,
    headers: {
      ...options.headers,
      Authorization: `Bearer ${session.access_token}`,
    },
  });

  if (!response.ok) {
    const errorData = await response.json().catch(() => ({}));
    throw new Error(errorData.detail || `Request failed: ${response.status}`);
  }
  return response.json();
}

Single point of JWT injection and error handling. All CRUD functions (fetchSubjects, fetchPlan, updatePlan, deleteSubject) are built on top. File uploads use FormData for multipart encoding.

Sticky top bar with three rendering zones: desktop links, desktop actions (theme toggle + auth buttons), and a mobile hamburger dropdown. Uses useAuth() for conditional login/logout UI and useTheme() for sun/moon toggle. All links use React Router's <Link> for client-side navigation.

Overlay modal with email/password form and Google/GitHub OAuth buttons. Key patterns:

14
Dashboard — The Core Study Hub

The largest component (829 lines). Key features:

  • Data loading: useEffect fetches subjects + plans in parallel with Promise.all(). A cleanup flag prevents state updates after unmount.
  • Optimistic UI: Marks topics complete instantly, recalculates progress, persists to backend asynchronously in background.
  • AI Tutor Chat: Sends topic + message + history to /api/v1/chat, displays conversation bubbles.
  • Resource Links: Auto-generates YouTube and Google search URLs per topic.
  • Schedule Editor: Modal to modify exam date and study hours.
  • Subject Management: Dropdown selector, delete with confirmation.

AI Integration

  • Primary Model: gemini-3.6-flash
  • Fallback Model: gemini-3.5-flash-lite
  • Structured Output: Pydantic schema enforced via Gemini API
  • Retry: 3 attempts, exponential backoff (2s → 4s → 8s)
  • Circuit Breaker: 60s cooldown after 5 consecutive failures
